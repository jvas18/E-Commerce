# 🛒 E-Commerce User Behavior Analysis

An in-depth analysis of user behavior across more than 5 million events in an e-commerce platform. This project explores the customer journey from **product view** to **cart** to **purchase**, using real-world big data and Python.

---

## 📌 Project Overview

This project aims to uncover insights from a large e-commerce dataset by:

- 🧹 Cleaning and preprocessing 5GB+ of raw event data
- 📊 Performing exploratory data analysis (EDA)
- 🔍 Identifying behavior patterns by product category, brand, and time of day
- 🛍️ Mapping the full conversion funnel: **View → Cart → Purchase**
- 📈 Visualizing key metrics for business understanding

---

## 🧠 Key Insights

- Peak conversion hours identified across user sessions
- Top-performing product categories and brands
- Funnel drop-off rates and user engagement analysis
